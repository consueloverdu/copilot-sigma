How a case works

The offline round is not a warm-up. It is what produces the judgement you will then use to weigh the tool's answer. Skip it and you will accept whatever comes out first.

8'
Offline roundNo computer. Read the sources, state the decision, work out one reference figure by hand and note the gaps.
12'
Copilot roundAttach only the files for this case, paste the base request and send the prompts in order.
7'
AuditLook for unsupported claims, calculations you cannot reproduce, hidden assumptions and decisions that need a human.

The base request · paste it at the start of every case

After attaching the files and before the first case-specific prompt. It is the same for all sixteen cases.

Prompt to copy
Use only the attached files. First state what you can and cannot assert. Then answer the objective of the case, pointing for each conclusion to the source and the data that support it. Separate facts, calculations, inferences and assumptions. If data is missing, do not invent it: formulate the question that would unblock the decision. Finish with a check that another person can reproduce.

The audit counter-prompt · for the last seven minutes

Prompt to copy
Act as a sceptical reviewer. Examine your previous answer using only the attached files. Build a table with: claim, type —fact, calculation, inference or assumption—, exact source, confidence level and pending check. Flag any calculation that cannot be reproduced, any unit that is not comparable, any possible double counting and any causal relationship that has not been demonstrated. Rewrite the recommendation if the evidence does not support it.
The golden rule The case data is synthetic and deliberately incomplete. Do not fill the gaps with real information about the company, customers, plants, suppliers or employees. The gaps are part of the exercise. No Copilot output is a decision: it is a draft until a person has checked sources, calculations and authority.
